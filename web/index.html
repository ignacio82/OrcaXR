Why use an external slicer?
The in-browser WebAssembly (WASM) slicer has a hard memory limit of 4GB, which can crash on very large models.

By running the External Slicer via Docker, you use the official Snapmaker Orca Slicer native binary instead, which avoids this memory limit and slices significantly faster.
Offline

A local http:// server works on Chrome 142+ after Local Network Access permission. The Docker server already enables CORS; use HTTPS for untrusted or remote networks. A server published beyond loopback requires ORCAXR_SERVER_TOKEN — paste it above. The token is kept for this tab only and is never saved to disk, so re-enter it after a reload.
